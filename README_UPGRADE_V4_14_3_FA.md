# راهنمای ارتقا به نسخه ۴.۱۴.۳

1. از مخزن GitHub فعلی یک نسخه پشتیبان بگیرید.
2. ZIP کامل نسخه ۴.۱۴.۳ را در ریشه مخزن جایگزین کنید.
3. مقدار Repository Variable با نام `BAZR_API_BASE_URL` را بررسی کنید؛ باید URL کامل HTTPS و دارای `/` در انتها باشد.
4. Workflow را از بخش Actions اجرا کنید.
5. APK را با همان کلید امضای نسخه نصب‌شده قبلی نصب کنید؛ برنامه قبلی را حذف نکنید.
6. وارد برنامه شوید و صفحه «پیش‌نویس‌ها» و «ادارات مجاز» را باز کنید.

## نکته مهم
از Clear Data یا حذف برنامه استفاده نکنید. اصلاح این نسخه به داده‌های محلی دست نمی‌زند. اگر صفحه بازیابی خطا ظاهر شد، دکمه «ارسال گزارش فنی خطا» را بزنید و متن گزارش را ارسال کنید.
