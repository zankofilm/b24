# راهنمای ارتقای اپ بازرس به نسخه ۴.۱۷.۰

## قبل از نصب
1. از Repository فعلی GitHub و APK سالم نسخه ۴.۱۶ پشتیبان بگیرید.
2. اطلاعات برنامه و حافظه گوشی را پاک نکنید؛ Clear Data باعث حذف سوابق محلی می‌شود.
3. اگر APK فعلی از همان کلید امضای قبلی ساخته شده، APK جدید را روی همان نصب به‌روزرسانی کنید. اگر خطای امضا دیدید، نسخه قبلی را حذف نکنید و ابتدا گزارش دهید.

## ساخت APK در GitHub
1. محتوای ZIP سورس کامل را در ریشه Repository جایگزین کنید.
2. در Settings → Secrets and variables → Actions، متغیر `BAZR_API_BASE_URL` را با آدرس کامل HTTPS API و اسلش انتهایی تنظیم کنید؛ نمونه: `https://example.com/bazr/api/`.
3. در Actions، Workflow ساخت Android را اجرا کنید.
4. ابتدا تست‌های Unit و سپس Build اجرا می‌شوند. Artifact با نام `bazr-inspector-4.17.0-apk` خواهد بود.

## نصب روی گوشی و آزمون
1. APK را نصب/به‌روزرسانی کنید.
2. وارد حساب بازرس شوید و مأموریت‌ها را همگام‌سازی کنید.
3. یک مأموریت را باز کنید؛ از یکی از شاخص‌ها گزینه «ثبت نقص برای این شاخص» را بزنید.
4. شرح حداقل ۸ نویسه، شدت و مهلت را تعیین و ذخیره کنید.
5. در حالت بدون اینترنت، رکورد باید روی گوشی باقی بماند و وضعیت «در انتظار اتصال سرور» نشان داده شود.
6. اینترنت را وصل و «همگام‌سازی نقص با سامانه» را اجرا کنید؛ پس از رسید معتبر، وضعیت «همگام‌شده» نمایش داده می‌شود.
7. در پنل وب، بخش «نواقص و اقدامات اصلاحی» را باز کنید؛ رکورد باید با برچسب منبع «اپلیکیشن بازرس» دیده شود.
8. پس از همگام‌سازی، وضعیت را از «ثبت‌شده» به «در حال پیگیری» تغییر دهید و توضیح اقدام وارد کنید.
9. سپس «در انتظار تأیید سربازرس» را ثبت کنید. تأیید یا رد نهایی را از پنل مجاز انجام دهید و در اپ همگام‌سازی کنید.
10. یک نقص ثبت‌شده توسط بازرس دیگر یا پنل وب را باز کنید؛ باید فقط‌خواندنی باشد.

## نکات ایمنی
- نسخه قبلی ۴.۱۶ را تا پایان آزمون حفظ کنید.
- برای نقص‌های جدید، اول ثبت محلی انجام می‌شود؛ تا دریافت رسید سرور، تغییر وضعیت بعدی مجاز نیست.
- برای ثبت اقدام/تغییر وضعیت، نشست معتبر و اینترنت لازم است؛ در صورت قطع اینترنت، وضعیت قبلی حفظ می‌شود.
- اگر همگام‌سازی خطا داد، رکورد محلی حذف نمی‌شود؛ از دکمه تلاش مجدد یا همگام‌سازی کلی استفاده کنید.
- API و تنظیمات خصوصی هاست تغییر داده نشده‌اند. برای سرور ۹.۲.۰ SQL جدید لازم نیست.
