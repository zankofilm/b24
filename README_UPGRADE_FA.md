# ارتقای رابط کاربری اپلیکیشن بازرس — نسخه ۴.۱۲.۰

## هدف
بازطراحی ورود، احراز هویت بیومتریک و داشبورد Native Android مطابق طرح تصویب‌شده سرمه‌ای/طلایی فرمانداری جوانرود. منطق API، شناسه مأموریت‌ها، ذخیره امن پیش‌نویس‌ها، ارسال گزارش، امضای دیجیتال و کارتابل سربازرس حفظ شده‌اند.

## فایل‌ها
- فایل‌های ریشه بسته (`app/`, `settings.gradle.kts`, `.github/`): سورس کامل Native Android/Kotlin آماده GitHub
- `CHANGELOG_V4_12_0_FA.md`: تغییرات نسخه
- `TEST_REPORT_V4_12_0_FA.md`: بررسی‌های انجام‌شده و موارد نیازمند تست روی GitHub/گوشی

## نصب در GitHub
1. از مخزن فعلی یک branch یا backup بگیرید.
2. محتویات ZIP نسخه کامل را مستقیماً در ریشه مخزن GitHub قرار دهید؛ فایل‌های `settings.gradle.kts` و پوشه `app/` باید در ریشه مخزن باشند و workflow نیز در `.github/workflows/` قرار دارد.
3. در Settings → Secrets and variables → Actions → Variables، متغیر `BAZR_API_BASE_URL` را با آدرس کامل HTTPS API که به `/` ختم می‌شود تنظیم کنید.
4. از Actions، workflow ساخت APK را با `Run workflow` اجرا کنید.
5. پس از موفقیت build، از بخش Artifacts فایل `bazr-inspector-debug` را دریافت کنید.

## صفحات جدید
- Splash رسمی با نشان بازرسی، پرچم و تصویر ساختمان
- ورود با فرم بومی، ذخیره اختیاری نام کاربری، نمایش/مخفی‌سازی رمز و راهنمای امنیتی
- صفحه تأیید اثر انگشت با طراحی مستقل
- داشبورد سرمه‌ای/طلایی با کارت معرفی بازرس، آمار، شروع بازرسی، گزارش رسمی و دسترسی سریع به پیش‌نویس‌ها/امضا
- نوار بالایی و ناوبری پایین هماهنگ با هویت بصری جدید

## نکات امنیتی و عملکردی
- رمز عبور ذخیره نمی‌شود؛ گزینه «مرا به خاطر بسپار» فقط نام کاربری را نگه می‌دارد.
- ورود با اثر انگشت فقط در صورت فعال بودن بیومتریک و وجود توکن رمزنگاری‌شده قبلی نمایش داده می‌شود.
- ورود اولیه همچنان با API و تأیید دستگاه طبق روال قبلی انجام می‌شود.
- آدرس API نمونه `example.invalid` است؛ حتماً مقدار واقعی سامانه خود را در متغیر GitHub تنظیم کنید.

## محدودیت تست
در محیط فعلی Android SDK و Gradle نصب نیست؛ بنابراین APK در اینجا کامپایل یا روی گوشی واقعی اجرا نشده است. ساخت نهایی باید در GitHub Actions انجام شود و نتیجه سبز workflow، تست ورود، اثر انگشت، داشبورد، مأموریت‌ها، امضا و ارسال گزارش بررسی شود.
