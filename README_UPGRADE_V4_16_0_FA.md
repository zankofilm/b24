# راهنمای ارتقا به BAZR Android 4.16.0

## فایل مورد استفاده
ZIP کامل را در ریشه مخزن GitHub جایگزین کنید. در این نسخه API، پایگاه داده و تنظیمات هاست تغییر نکرده‌اند.

## پیش از نصب
1. نسخه فعلی را حذف نکنید.
2. از اطلاعات محلی گوشی و مخزن GitHub نسخه پشتیبان داشته باشید.
3. برای نصب روی نسخه قبلی، APK باید با همان کلید امضای قبلی ساخته شود؛ APK دیباگ یا امضای متفاوت ممکن است روی نسخه نصب‌شده به‌روزرسانی نشود.
4. مقدار Repository Variable به نام `BAZR_API_BASE_URL` باید آدرس HTTPS کامل API و دارای `/` پایانی باشد.

## ساخت APK
1. فایل‌ها را در ریشه Repository قرار دهید.
2. به تب Actions بروید.
3. Workflow با نام `Build BAZR Inspector Android (debug)` را اجرا کنید.
4. منتظر موفقیت مرحله `Run unit tests` و سپس `Build stable signed release APK` یا `Build debug APK` بمانید.
5. Artifact با نام `bazr-inspector-4.16.0-apk` را دریافت کنید.

## آزمون پس از نصب
- ورود و همگام‌سازی مأموریت‌ها.
- بازکردن مأموریت دارای چک‌لیست چندشاخصی.
- ثبت امتیاز با ارقام فارسی و لاتین.
- انتخاب هر پنج سطح سریع و کنترل مقدار عددی ذخیره‌شده.
- ثبت توضیح برای امتیاز کمتر از ۶۰.
- ثبت مستند برای امتیاز کمتر از ۳۰ و شاخص بحرانی.
- بازکردن «نمای کلی شاخص‌ها» و رفتن به اولین بند ناقص.
- خروج از نمای کلی با دکمه بالای صفحه و دکمه Back اندروید.
- بستن و بازکردن برنامه و اطمینان از حفظ پیش‌نویس.
- مرور گزارش، امضای لمسی و قرارگیری در صف ارسال.

## نکته مهم
بندهای بدون امتیاز صفر نمی‌شوند. در مسیر امضا باید هشدار و تأیید صریح بازرس نمایش داده شود. هیچ امتیاز نهایی یا وزن‌دهی جدیدی در کلاینت محاسبه نشده است.
