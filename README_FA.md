# BAZR Android 4.14.3 — Draft Crash Guard

این نسخه برای جلوگیری از بسته‌شدن برنامه هنگام ورود به بخش «پیش‌نویس‌ها» آماده شده است.

## نصب از GitHub
1. از مخزن فعلی نسخه پشتیبان بگیرید.
2. محتوای ZIP کامل را در ریشه مخزن جایگزین کنید.
3. مقدار Repository Variable با نام `BAZR_API_BASE_URL` باید URL کامل HTTPS API و دارای `/` در انتها باشد.
4. از بخش Actions، Workflow ساخت اندروید را اجرا کنید.
5. APK ساخته‌شده را نصب و بخش پیش‌نویس‌ها را آزمایش کنید.

## اگر خطا دوباره رخ داد
صفحه بازیابی به‌جای بسته‌شدن برنامه نمایش داده می‌شود. دکمه «ارسال گزارش فنی خطا» را بزنید و متن گزارش را برای پشتیبانی ارسال کنید.

## حفاظت از اطلاعات
گزارش فنی فقط نسخه برنامه، نسخه Android، نام بخش، نوع خطا و stack trace را نگه می‌دارد؛ متن پیش‌نویس‌ها، توکن ورود، نام اداره‌ها و تصاویر/فایل‌های مستند را ثبت نمی‌کند.

**مهم:** پیش از نصب، برنامه قبلی را حذف نکنید و Clear Data نزنید. نصب روی همان package id باید اطلاعات محلی را نگه دارد. برای به‌روزرسانی روی نسخه نصب‌شده، APK باید با همان کلید امضا شده باشد.
