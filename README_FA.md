# اپلیکیشن Native بازرسی ادارات — نسخه ۴.۱۲.۰

این پروژه سورس کامل اپلیکیشن اندروید بومی (Kotlin / Android Views) است؛ WebView نیست. هویت بصری جدید سرمه‌ای و طلایی، صفحه آغاز رسمی، ورود سازمانی، احراز هویت اثر انگشت و داشبورد مطابق طرح مصوب در این نسخه پیاده‌سازی شده است.

## ساختار پروژه

- `app/` — سورس برنامه، منابع تصویری و آیکون‌ها
- `build.gradle.kts` و `settings.gradle.kts` — پیکربندی Gradle
- `.github/workflows/android.yml` — ساخت خودکار APK در GitHub Actions
- `CHANGELOG_V4_12_0_FA.md` — شرح تغییرات
- `TEST_REPORT_V4_12_0_FA.md` — گزارش بررسی و تست‌های لازم

## تنظیم آدرس API

در GitHub به مسیر زیر بروید:

`Settings → Secrets and variables → Actions → Variables`

یک Repository variable با نام `BAZR_API_BASE_URL` بسازید و آدرس واقعی API را وارد کنید. مقدار باید HTTPS باشد و با `/` تمام شود؛ برای مثال:

`https://YOUR-DOMAIN.example/bazr/api/`

آدرس نمونه `https://example.invalid/api/` فقط مقدار پیش‌فرض محافظتی است و برای اتصال واقعی مناسب نیست.

## ساخت APK در GitHub

1. محتویات ZIP را مستقیماً در ریشه مخزن GitHub بارگذاری کنید؛ پوشه‌های `app/` و `.github/` باید در ریشه باشند.
2. مقدار `BAZR_API_BASE_URL` را طبق بخش قبل تنظیم کنید.
3. به تب `Actions` بروید و workflow با نام `Build BAZR Inspector Android (debug)` را اجرا کنید.
4. پس از سبز شدن workflow، از بخش Artifacts فایل `bazr-inspector-debug` را دریافت کنید.

## ساخت در Android Studio

پوشه‌ای را باز کنید که فایل `settings.gradle.kts` در ریشه آن قرار دارد. JDK 17، Android SDK 35، Gradle 8.13 و Android Gradle Plugin 8.9.2 استفاده می‌شوند. آدرس API را در فایل محلی `~/.gradle/gradle.properties` با کلید `BAZR_API_BASE_URL` تنظیم کنید.

## قابلیت‌های حفظ‌شده

منطق API، ورود و تأیید دستگاه، اثر انگشت، کارتابل سربازرس، دسترسی محدود به ادارات، چک‌لیست ۸۶ بندی صفحه‌بندی‌شده، ذخیره امن پیش‌نویس، پیوست عکس/PDF، امضای دیجیتال، صف ارسال و دریافت PDF رسمی در این بازطراحی حذف نشده‌اند.

## امنیت

- رمز عبور در گوشی ذخیره نمی‌شود.
- گزینه «مرا به خاطر بسپار» فقط نام کاربری را ذخیره می‌کند.
- توکن دستگاه و داده‌های حساس با سازوکارهای امن Android نگهداری می‌شوند.
- ورود با اثر انگشت تنها پس از فعال‌سازی توسط خود بازرس قابل استفاده است.

## وضعیت تأیید

سورس و منابع XML از نظر ساختار بررسی شده‌اند؛ اما در محیط تولید این بسته Android SDK و Gradle در دسترس نبود، بنابراین APK کامپایل یا روی گوشی واقعی آزمایش نشده است. قبل از انتشار، موفقیت GitHub Actions و تست ورود، بیومتریک، مأموریت، عکس، امضا و ارسال گزارش الزامی است.
