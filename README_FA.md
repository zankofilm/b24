# سامانه بازرسی ادارات — Android Native 4.16.0

اپلیکیشن بومی اندروید بازرس با رابط فارسی راست‌چین، هویت بصری سرمه‌ای/سفید/طلایی و اتصال به API فعلی سامانه.

## ماژول‌ها
- ورود امن، نشست دستگاه و ورود بیومتریک
- داشبورد و مأموریت‌های ابلاغ‌شده
- فرم بازرسی مرحله‌ای بر اساس snapshot سرور
- موتور مشترک ارزیابی ۸۶ شاخص و نمای کلی پیشرفت هر شاخص
- ذخیره امن پاسخ‌ها، توضیحات و مستندات
- امضای لمسی و مرور پیش از ثبت
- صف ارسال، ارسال گروهی، پیشرفت و تلاش مجدد
- گزارش رسمی و PDFهای سرور
- سوابق، رسیدها، گزارش‌های تحلیلی و کارتابل سربازرس

## ارتقای 4.16.0
- موتور یکپارچه `ChecklistAssessment` برای پیشرفت، وضعیت هر بند و اعتبارسنجی پیش از امضا
- نمای کلی شاخص‌ها با امکان پرش به اولین بند ناقص
- نمایش زنده وضعیت هر بند: بدون امتیاز، امتیاز نامعتبر، نیازمند توضیح، نیازمند مستند و تکمیل‌شده
- نمایش هشدار شاخص‌های بحرانی
- پنج سطح ورود سریع: بسیار ضعیف ۰، ضعیف ۲۵، متوسط ۵۰، خوب ۷۵ و عالی ۱۰۰
- حفظ ورود عددی آزاد ۰ تا ۱۰۰ و قواعد قبلی توضیح/مستند
- عدم تغییر API، دیتابیس، شناسه‌های سرور، ساختار رمزنگاری پیش‌نویس یا فرمول نهایی امتیازدهی

## ساخت در GitHub Actions
1. از مخزن فعلی پشتیبان بگیرید.
2. محتوای ZIP را در ریشه مخزن قرار دهید.
3. Repository Variable با نام `BAZR_API_BASE_URL` را با نشانی کامل HTTPS API و `/` انتهایی تنظیم کنید.
4. از مسیر Actions، گردش‌کار `Build BAZR Inspector Android (debug)` را اجرا کنید.
5. فایل APK را از بخش Artifacts با نام `bazr-inspector-4.16.0-apk` دریافت کنید.

## نکات نصب و نگهداری داده
- برنامه قبلی را حذف نکنید و `Clear Data` نزنید.
- برای نصب روی نسخه موجود، APK باید با همان کلید امضا شده باشد.
- گزارش ارسال‌شده فقط پس از دریافت رسید معتبر سرور موفق محسوب می‌شود.
- پیش‌نویس‌ها و مستندات محلی رمزنگاری‌شده‌اند؛ در صورت خطا، داده برنامه را پاک نکنید.

## پیکربندی
- `BAZR_API_BASE_URL`: آدرس HTTPS API، از طریق Gradle property یا Repository Variable.
- برای انتشار پایدار، secrets امضای release در workflow پیکربندی شوند؛ در غیر این صورت artifact debug برای تست تولید می‌شود.
