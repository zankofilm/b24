# سامانه بازرسی ادارات — Android Native

**نسخه: 4.14.2**  
**versionCode: 27**  
**پلتفرم: Android Native / Kotlin**

این پروژه نسخه بومی اندروید سامانه بازرسی ادارات است. طراحی رابط کاربری بر اساس تصویر مرجع تأییدشده در `design/BAZR_UI_REFERENCE_V4_14.png` انجام شده است.

## ساختار رابط کاربری

- ورود سازمانی با هویت بصری سرمه‌ای، سفید و طلایی
- داشبورد با کارت خوشامدگویی، آمار، شروع بازرسی و مأموریت‌های اخیر
- فرم بازرسی مرحله‌ای با گروه‌بندی شاخص‌ها، ذخیره پیش‌نویس و نمایش پیشرفت
- فهرست مأموریت‌ها با جست‌وجو و فیلتر
- پیش‌نویس‌ها با وضعیت هر مورد و دسترسی به صف ارسال
- گزارش‌ها و تحلیل‌ها با بازه هفتگی، ماهانه و سالانه
- گزارش رسمی و دریافت PDF
- پروفایل و تنظیمات امنیتی

## حفظ قابلیت‌های قبلی

مسیرهای قبلی ورود، API، همگام‌سازی، مأموریت‌ها، چک‌لیست، پیش‌نویس رمزنگاری‌شده، امضای دیجیتال، صف ارسال، گزارش رسمی و PDF حفظ شده‌اند. این نسخه تغییری در قرارداد API یا ساختار دیتابیس ایجاد نمی‌کند.

## تنظیم API برای GitHub Actions

در تنظیمات مخزن GitHub یک Repository Variable با نام `BAZR_API_BASE_URL` تعریف کنید. مقدار باید آدرس کامل HTTPS API باشد و با `/` تمام شود؛ برای نمونه:

`https://example.com/api/`

این فقط نمونه است و باید با آدرس واقعی API جایگزین شود.

## ساخت APK

Workflow در `.github/workflows/android.yml` قرار دارد. در مسیر **Actions → Build BAZR Inspector Android (debug) → Run workflow** اجرا کنید. Workflow ابتدا بررسی منابع و `:app:testDebugUnitTest` را اجرا می‌کند و سپس APK را می‌سازد.

برای ساخت Release قابل نصب روی نسخه قبلی، همان keystore و alias نسخه منتشرشده قبلی را در Secrets مخزن تنظیم کنید:

- `BAZR_KEYSTORE_BASE64`
- `BAZR_KEYSTORE_PASSWORD`
- `BAZR_KEY_ALIAS`
- `BAZR_KEY_PASSWORD`

**هشدار:** تا قبل از تأیید امضای یکسان و پشتیبان‌گیری از داده‌های محلی، نسخه قبلی را حذف نکنید.
