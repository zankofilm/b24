## تنظیم API برای GitHub Actions

در مخزن GitHub یک Repository Variable با نام `BAZR_API_BASE_URL` بسازید. مقدار باید آدرس کامل HTTPS API و با `/` تمام شود؛ برای نمونه:

`https://example.com/api/`

آدرس نمونه بالا واقعی نیست و باید با آدرس API خود سامانه جایگزین شود.

## ساخت APK

Workflow در مسیر `.github/workflows/android.yml` قرار دارد. پیش از تست Gradle، اسکریپت `tools/verify_android_source.py` منابع XML/Drawable و هماهنگی نسخه Artifact را بررسی می‌کند. از مسیر **Actions → Build BAZR Inspector Android (debug) → Run workflow** اجرا کنید.

Workflow ابتدا `:app:testDebugUnitTest` و سپس APK را می‌سازد. در صورت تنظیم secrets امضای پایدار، خروجی Release و در غیر این صورت خروجی Debug تولید می‌شود.

### امضای پایدار Release

برای ساخت Release قابل نصب روی نسخه قبلی، همان keystore و alias مورد استفاده نسخه منتشرشده قبلی را در secrets مخزن تنظیم کنید:

- `BAZR_KEYSTORE_BASE64`
- `BAZR_KEYSTORE_PASSWORD`
- `BAZR_KEY_ALIAS`
- `BAZR_KEY_PASSWORD`

**هشدار:** برای حفظ امکان ارتقا، برنامه نصب‌شده قبلی را پیش از تأیید امضای یکسان و پشتیبان‌گیری از داده‌های محلی حذف نکنید.
