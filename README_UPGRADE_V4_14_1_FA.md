# راهنمای ارتقا به 4.14.1

1. از مخزن فعلی GitHub یک نسخه پشتیبان بگیرید.
2. محتویات ZIP کامل را در ریشه مخزن جایگزین کنید؛ پوشه `app/` باید کنار `settings.gradle.kts` قرار گیرد.
3. مقدار `BAZR_API_BASE_URL` را در Repository Variables بررسی کنید.
4. Workflow را از Actions اجرا کنید.
5. ابتدا نتیجه `testDebugUnitTest` و سپس مرحله `assembleDebug` یا `assembleRelease` را بررسی کنید.
6. APK را روی یک دستگاه آزمایشی نصب و ورود، اثر انگشت، همگام‌سازی، بازکردن مأموریت، ذخیره پیش‌نویس، امضا، صف ارسال و دریافت PDF را تست کنید.

## مهم

- این نسخه API یا دیتابیس را تغییر نمی‌دهد.
- برای نصب روی نسخه موجود، باید APK با کلید امضای نسخه قبلی امضا شده باشد.
- تا قبل از تأیید موفق نصب و حفظ داده‌های محلی، نسخه قبلی را حذف نکنید.
- ساخت و اجرای واقعی APK در محیط تحویل انجام نشده است؛ نتیجه نهایی کامپایل باید از GitHub Actions دریافت شود.
