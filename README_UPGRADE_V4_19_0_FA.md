# راهنمای ارتقای BAZR Android 4.19.0

## تغییرات
مرکز مستندات، آرشیو محلی و سروری، جست‌وجو و فیلتر، مشاهده مستندات و اتصال به شاخص مرتبط اضافه شده است. مستندات محلی از رکوردهای رمزنگاری‌شده پیش‌نویس و نواقص جمع‌آوری می‌شوند؛ هیچ فایل یا رکوردی در زمان ساخت آرشیو حذف یا بازنویسی نمی‌شود.

## نصب سرور
1. از پوشه `api/` نسخه پشتیبان بگیرید.
2. فایل `api/mobile_evidence_library.php` را در پوشه `api/` سامانه BAZR قرار دهید.
3. این endpoint فقط GET و نشست معتبر اپ بازرس را می‌پذیرد و فقط فایل‌های همان `mobile_user_id` در مأموریت‌های تخصیص‌یافته را برمی‌گرداند.
4. SQL جدید لازم نیست. دانلود باینری از endpoint موجود `mobile_file.php` انجام می‌شود.

## نصب اندروید
1. از Repository نسخه ۴.۱۸ پشتیبان بگیرید.
2. سورس کامل ۴.۱۹ را در ریشه مخزن جایگزین کنید.
3. مقدار Repository Variable با نام `BAZR_API_BASE_URL` باید آدرس HTTPS کامل API و دارای `/` پایانی باشد.
4. GitHub Actions را اجرا و Artifact `bazr-inspector-4.19.0-apk` را دریافت کنید.
5. APK را روی نسخه ۴.۱۸ نصب کنید؛ Clear Data نزنید و برنامه قبلی را قبل از تست حذف نکنید.

## سناریوی آزمون
- در یک پیش‌نویس یک عکس و یک PDF به دو شاخص اضافه کنید.
- در مرکز مستندات، فیلتر تصاویر و PDF را جداگانه آزمایش کنید.
- یک نقص دارای مستند را نیز باز کنید و مطمئن شوید همان فایل در آرشیو فقط یک ردیف با دو زمینه مرتبط دارد.
- گزارش را ارسال کنید؛ پس از دریافت رسید، مستند در آرشیو سرور نمایش داده شود.
- از دکمه مشاهده، یک فایل سروری را دریافت کنید.
- در حالت آفلاین، مستند محلی همچنان باید قابل مشاهده باشد.

## نکته
APK واقعی باید در GitHub Actions ساخته شود. اتصال زنده API و رفتار فایل‌ها روی هاست و گوشی واقعی باید در سناریوی بالا تأیید شود.
