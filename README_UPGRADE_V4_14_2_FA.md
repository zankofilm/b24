# راهنمای ارتقا به نسخه 4.14.2

1. از مخزن GitHub فعلی یک نسخه پشتیبان بگیرید.
2. محتویات ZIP کامل نسخه 4.14.2 را در ریشه مخزن قرار دهید؛ پوشه `app/` باید کنار `settings.gradle.kts` باشد.
3. متغیر مخزن `BAZR_API_BASE_URL` را بررسی کنید؛ مقدار باید HTTPS و دارای `/` انتهایی باشد.
4. از بخش Actions، Workflow با نام `Build BAZR Inspector Android (debug)` را اجرا کنید.
5. موفقیت `:app:testDebugUnitTest` و سپس مرحله ساخت APK را بررسی کنید.
6. APK را روی گوشی آزمایشی نصب کنید و قابلیت‌های ورود، اثر انگشت، مأموریت‌ها، فرم بازرسی، پیش‌نویس، امضا، ارسال و PDF را تست کنید.

## نکات مهم

- این اصلاح، API یا دیتابیس را تغییر نمی‌دهد.
- برای نصب به‌صورت به‌روزرسانی روی برنامه قبلی، باید امضای APK با کلید نسخه قبلی یکسان باشد.
- تا قبل از تأیید نصب و حفظ داده‌های محلی، نسخه قبلی را حذف نکنید.
- نسخه 4.14.2 خطای کامپایل گزارش‌شده در انتخاب آخرین نقاط نمودار را اصلاح می‌کند؛ موفقیت نهایی Build باید در GitHub Actions تأیید شود.
