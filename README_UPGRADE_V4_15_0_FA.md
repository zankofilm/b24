# راهنمای ارتقا به 4.15.0

## روش پیشنهادی: جایگزینی سورس کامل
1. از Repository فعلی یک backup/branch بگیرید.
2. فایل `BAZR_Android_4_15_0_Native_Upgrade_GitHub_Source.zip` را در ریشه مخزن استخراج و جایگزین کنید.
3. مقدار `BAZR_API_BASE_URL` را در Repository Variables بررسی کنید.
4. GitHub Actions را اجرا کنید.
5. فقط پس از موفقیت workflow، APK را نصب کنید.

## تغییرات داده محلی
- هیچ داده‌ای پاک نمی‌شود.
- فیلد `updated_at` در رکورد رمزنگاری‌شده پیش‌نویس افزوده شده است.
- برای پیش‌نویس‌های قبلی که این فیلد را ندارند، `started_at` به‌عنوان زمان جایگزین خوانده می‌شود.
- API، کلیدهای ذخیره‌سازی قبلی، `submission_key`، شناسه مأموریت‌ها و ساختار صف ارسال تغییر نکرده‌اند.

## تست پس از نصب
1. ورود با نام کاربری/رمز عبور.
2. بازکردن مأموریت موجود و تغییر یک امتیاز؛ خروج و ورود مجدد به فرم.
3. بازکردن پیش‌نویس‌ها؛ فیلترها و جست‌وجو را آزمایش کنید.
4. یک گزارش امضاشده در صف را باز کنید؛ وضعیت و تعداد تلاش‌ها را ببینید.
5. در حالت آنلاین، یک گزارش آزمایشی مجاز را ارسال و دریافت رسید سرور را کنترل کنید.
6. گزارش‌های هفتگی/ماهانه/سالانه و PDF رسمی را باز کنید.

## هشدار
تا زمانی که APK با همان کلید امضا و روی دستگاه آزمایش نشده است، نسخه نصب‌شده را حذف نکنید. این بسته به‌تنهایی تأییدکننده اجرای واقعی روی گوشی نیست.
