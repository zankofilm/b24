# راهنمای نسخه ۴.۲۰.۰ – تقویم و مدیریت مأموریت‌ها

## امکانات
- تقویم شمسی مأموریت‌ها در حالت ماهانه، هفتگی و روزانه.
- شمارش مأموریت‌های هر روز و فهرست مأموریت‌های بدون تاریخ.
- خواندن برنامه از مأموریت‌های تخصیص‌یافته در پاسخ API فعلی؛ اطلاعات سرور مرجع نهایی است.
- یادآوری محلی یک ساعت پیش از مأموریت با WorkManager، در صورت وجود تاریخ و ساعت معتبر و اجازه اعلان.
- بازکردن موقعیت اداره در نقشه با مختصات یا نشانی موجود در ابلاغیه.
- بازکردن تقویم از لینک مأموریت در اعلان/ابلاغیه.

## نصب
1. از Repository نسخه ۴.۱۹ پشتیبان بگیرید.
2. سورس کامل را در ریشه Repository جایگزین کنید.
3. GitHub Actions را اجرا کنید و Artifact `bazr-inspector-4.20.0-apk` را دریافت کنید.
4. APK را روی نسخه ۴.۱۹ نصب کنید؛ اطلاعات برنامه را پاک نکنید.
5. پس از ورود، همگام‌سازی را اجرا و تقویم را بررسی کنید.

## محدودیت‌ها و الزامات داده
- تقویم در اپ بازرس فقط‌خواندنی است؛ ایجاد/ویرایش/تخصیص مأموریت باید از پنل سازمان و API فعلی انجام شود.
- برای نمایش در تقویم، رکورد مأموریت باید تاریخ شمسی یا میلادی قابل‌تشخیص در یکی از فیلدهای date/visit_date/scheduled_date/mission_date/schedule_label داشته باشد.
- برای یادآوری دقیق، ساعت نیز باید در یکی از فیلدهای time/start_time/scheduled_time/visit_time/schedule_time/schedule_label باشد.
- برای نقشه، مختصات latitude/longitude یا نشانی معتبر در رکورد لازم است. GPS پس‌زمینه یا ردیابی حضور اضافه نشده است.
- یادآوری محلی به مجوز اعلان و محدودیت‌های باتری/زمان‌بندی Android وابسته است و تضمین لحظه‌ای ندارد.
- SQL یا تغییر API سمت سرور لازم نیست؛ از داده مأموریت‌های موجود در همگام‌سازی استفاده می‌شود.

## تست پس از نصب
1. مأموریتی با تاریخ و ساعت معتبر در پنل تخصیص دهید.
2. در اپ همگام‌سازی و نمایش آن در روز صحیح تقویم را کنترل کنید.
3. حالت‌های ماهانه، هفتگی و روزانه را بررسی کنید.
4. یادآوری را برای مأموریتی که بیش از یک ساعت تا زمان آن باقی است تنظیم کنید.
5. دکمه نقشه را برای رکورد دارای نشانی/مختصات آزمایش کنید.
